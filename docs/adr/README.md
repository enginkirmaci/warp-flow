# ADRs

Architecture decisions for warp-flow. The numbers are inherited from
warp-suite: the family's contract decisions stay there (warp-flow's own door is
ADR-0012 there), so the series starts at 0008 and a new decision takes the next
free number in the family series (0017 after this repository's 0016).

Write one when a choice is hard to reverse and someone later will ask why. An
accepted ADR is not edited: supersede it with a new one that says so.
